# Catálogo de Produtos

Projeto desenvolvido com React, TypeScript e Vite.

## Requisitos atendidos

- Projeto criado com Vite
- Organização em `components`, `pages` e `assets`
- Componente `ProdutoCard` usando props
- Lista de produtos armazenada em `useState`
- Renderização dinâmica com `.map()`
- Simulação de carregamento com `useEffect` e `setTimeout`
- Mensagem de carregamento
- Formulário controlado
- Campos obrigatórios: nome, preço e descrição
- Cadastro de novos produtos no state
- Estilização com CSS
- Dados mockados, sem necessidade de API

## Como executar

```bash
npm install
npm run dev
```

Depois, abra o endereço mostrado pelo Vite no terminal.

## Build de produção

```bash
npm run build
```

## GitHub

Depois de testar o projeto, crie um repositório público no GitHub e execute:

```bash
git init
git add .
git commit -m "feat: cria catalogo de produtos"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/produtos-vite.git
git push -u origin main
```

Substitua `SEU-USUARIO` pelo seu usuário do GitHub.
